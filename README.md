# Morning Briefs / 晨報存檔

Private archive of daily morning briefs on artificial intelligence, US stocks, and cryptocurrency. Times are Asia/Hong Kong (GMT+8).

- [index.html](index.html) — date index, newest first
- [briefs/](briefs/) — one HTML file per day, named `YYYY-MM-DD.html`

Email drafts of the same brief continue to be prepared separately. Figures and headlines come from public sources and can change quickly. This archive is for information only and is not investment advice.

The repository is private and is used as a file store. To publish these pages as a website later, make the repository public and enable GitHub Pages from the `main` branch (site root).
