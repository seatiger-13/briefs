1. OpenAI and Cisco introduce Shirudo,

OpenAI 與 Cisco 推出 Shirudo，

an open-source runtime that can apply temporary, operator-approved Linux protections

一個開源運行時，可在營運人員批准後套用臨時 Linux 防護，

without waiting for a patch or restarting the system

而無需等待補丁或重啟系統

OpenAI said on 2026-11-23 that it was launching Shirudo with Cisco, an open-source runtime intended to help teams protect running Linux systems while they test and roll out patches.

OpenAI 於 2026-11-23 宣布與 Cisco 推出 Shirudo，這是一個開源運行時，旨在協助團隊在測試及部署補丁期間，保護正在運行的 Linux 系統。

The companies said testing and deploying a patch can still take days or weeks, and that blocking a Linux operation outright can take a service offline if an exploit and a legitimate request rely on the same operation.

兩家公司表示，測試及部署補丁仍可能需時數天甚至數週；若攻擊與正當請求依賴同一項 Linux 操作，直接封鎖該操作可能令服務中斷。

Shirudo, a name OpenAI said is Japanese for “shield,” uses eBPF so that a temporary safeguard, called a shield, can be tested and, once an operator approves it, deployed while the service continues running.

OpenAI 稱 Shirudo 在日語中意為「盾」；它使用 eBPF，讓稱為「shield」的臨時防護可先經測試，並在營運人員批准後，於服務繼續運行的情況下部署。

OpenAI said the design has four core capabilities: live protection without a restart; programmable controls that let agents investigate vulnerabilities and draft shields while security teams decide what is deployed; cryptographic signing and Linux eBPF verification before a shield is loaded; and hardware-backed records using a Trusted Platform Module, so operators can check whether protections were loaded or removed.

OpenAI 稱設計包含四項核心能力：可在不重啟的情況下作即時防護；讓智能體調查漏洞並草擬防護、但由保安團隊決定是否部署的可編程控制；防護載入前的加密簽署及 Linux eBPF 驗證；以及利用可信平台模組（TPM）保存硬體備份紀錄，讓營運人員查核防護是否已被載入或移除。

In a controlled test, the companies said, a Codex-generated shield blocked a Java4Shell exploit attempt against a running Elasticsearch service without requiring a restart, by adding an input check to Java’s Base64 decoder.

他們表示，在一項受控測試中，由 Codex 生成的防護為 Java 的 Base64 解碼器加入輸入檢查，在無需重啟的情況下，阻擋了針對正在運行的 Elasticsearch 服務的 Java4Shell 攻擊嘗試。

The project is licensed under the BSD 2-Clause license, with its BPF programs dual-licensed under BSD and GPL, and the companies are inviting operators and researchers to inspect the code, contribute shields, and join a webinar on December 15.

項目以 BSD 2-Clause 授權，其 BPF 程式同時以 BSD 及 GPL 雙重授權；兩家公司邀請營運人員及研究員檢查程式碼、貢獻防護，並參加 12 月 15 日的網絡研討會。

This brief treats the announcement as the launch of an open-source tool, not as evidence that the test result will hold on production systems generally.

本簡報將此公布視為開源工具的推出，而不把該測試結果視為已在一般生產系統上得到證實。

https://openai.com/index/introducing-shirudo/

2. Google DeepMind says Gemini 4 agent teams found faster quantum algorithms,

Google DeepMind 稱 Gemini 4 智能體團隊找出更快的量子算法，

and formally verified the results in Lean

並以 Lean 作出形式化驗證

Google DeepMind said on 2026-11-23 that teams of Gemini 4 agents had improved well-known quantum algorithms, producing more efficient quantum circuits, in a collaboration with Google Quantum AI.

Google DeepMind 於 2026-11-23 表示，Gemini 4 智能體團隊與 Google Quantum AI 合作，改進了已知的量子算法，並產生更有效率的量子電路。

Because resource-intensive circuits cannot be fully tested on classical computers or today’s small quantum processors, the company said the agent teams proved each result in Lean, a formal theorem prover.

該公司表示，由於資源密集的電路無法在經典電腦或現時小型量子處理器上完整測試，智能體團隊以形式化定理證明器 Lean 證明每一項結果。

Separate agent teams searched for improvements, Lean-verified ideas were added to a shared notebook, and every four hours agents from each team met at a virtual conference to compare ideas.

各獨立智能體團隊分頭尋找改進，經 Lean 驗證的構想會記入共用筆記；每四小時，各隊智能體會在虛擬會議中比較構思。

The post said one circuit used to calculate a property of inertial confinement fusion cut the required computing cost — a metric combining qubits and operations — by 11.8 times, and lowered required memory from 5,650 to 4,338 error-corrected qubits.

文章稱，一條用於計算慣性約束聚變某項性質的電路，把所需計算成本（結合量子比特與操作次數的度量）降低 11.8 倍，所需記憶體由 5,650 個減至 4,338 個糾錯量子比特。

It also reported an 8 times cost reduction for simulating a common light-sensitive molecule, a 2.5 times improvement for Cytochrome P450 that lowered memory from 481 to 333 qubits, a 2.57 times speedup for a specific implementation of Grover’s algorithm, and a 290 times speedup for a fixed-point arcsin routine used to load numbers into quantum states.

文章亦稱，模擬一種常見光敏分子的成本降低 8 倍；針對細胞色素 P450 的改進達 2.5 倍，記憶體由 481 個減至 333 個量子比特； Grover 算法的一個特定實現加快 2.57 倍；而用於把數字載入量子態的定點反正弦常式則加快 290 倍。

DeepMind said running these algorithms in scientific simulations would still demand more resources than the first error-corrected quantum computers are likely to provide, but that the improvements are significant.

DeepMind 表示，若要在科學模擬中運行這些算法，所需資源仍可能高於第一批糾錯量子電腦預計能提供的水平，但這些改進仍屬可觀。

The company is open-sourcing its Lean library, problem specifications and verified solutions on GitHub.

該公司正把其 Lean 程式庫、問題規格及已驗證的解法在 GitHub 開源。

https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/

文章並稱，AI Overviews 及 AI Mode 將開始顯示更多根據近期搜尋脈絡度身而設的回應，例如延續行程規劃討論而無須從頭再來。

4. Google adds file-slicing controls to the Gemini API,

Google 為 Gemini API 加入檔案切片控制，

so developers can load only selected pages, sheet ranges or media segments

讓開發者只載入選定頁面、工作表範圍或媒體片段

Google DeepMind product and engineering staff wrote on 2026-11-23 that the Gemini API now has native file-slicing controls in Google AI Studio and on the Gemini platform, alongside native upload support for Microsoft Office and OpenDocument formats.

Google DeepMind 產品及工程人員於 2026-11-23 撰文，指 Gemini API 現已在 Google AI Studio 及 Gemini 平台提供原生檔案切片控制，並同時支援直接上載 Microsoft Office 及 OpenDocument 格式。

Developers can upload a file once with the Files API, reuse its URI, and ask the model to inspect only specified pages, spreadsheet cells, media time ranges and content layers, so tokens are billed for the parts the model inspects rather than the whole file.

開發者可用 Files API 上載一次檔案、重複使用其 URI，並要求模型只檢視指定頁面、試算表儲存格、媒體時間範圍及內容層，從而以模型實際檢視的部分計算 token，而非整份檔案。

For documents and slides, the API can take a page range, a resolution and content layers such as page text or page images; for spreadsheets, a sheet index, visible cells, resolution and layers such as data, formulas and visuals; and for video and audio, start and end offsets, with frame-rate and layer options for video.

文件及投影片可設定頁面範圍、解析度，以及頁面文字或頁面圖像等內容層；試算表可設定工作表索引、可見儲存格、解析度，以及數據、公式及視覺元素等層；影片及音訊可設定起訖時間，影片另可調整幀率及內容層。

The company said the controls work across all Gemini 4 models, and that existing file-size and page limits still apply to the uploaded file.

該公司表示，這些控制適用於所有 Gemini 4 模型，已上載檔案仍受現有檔案大小及頁數限制約束。

https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/
